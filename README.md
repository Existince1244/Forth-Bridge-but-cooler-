# The Forth Bridge

A static website about the Forth Bridge — Scotland's iconic Victorian cantilever railway bridge and UNESCO World Heritage Site.

## Live site

> Once deployed, update this link:
> **https://your-username.github.io/forth-bridge**

## About

This site covers:

- **Overview** — key facts and figures at a glance
- **History** — timeline from the 1879 Tay Bridge disaster to UNESCO inscription in 2015
- **Engineering** — cantilever design, dimensions, materials, and the famous human cantilever demonstration
- **Heritage** — UNESCO status, cultural significance, and the "painting the Forth Bridge" idiom
- **Visitors** — how to get there, what to see, and nearby attractions

## Stack

Plain HTML, CSS, and vanilla JavaScript. No build tools, no dependencies. Deploys directly on GitHub Pages.

## Deploy to GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings → Pages**.
3. Under **Source**, select **Deploy from a branch**.
4. Choose `main` branch and `/ (root)` folder.
5. Click **Save**. Your site will be live at `https://<your-username>.github.io/<repo-name>`.
